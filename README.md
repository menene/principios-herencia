# Personajes base

Programa de consola en Java que muestra el movimiento y el ataque de un caballero, un arquero y un mago.

## Requisito

Es necesario tener instalado un JDK.

## Compilar y ejecutar

Desde la carpeta del proyecto, ejecuta:

```sh
javac -encoding UTF-8 -d bin src/*.java
java -cp bin Main
```

## Salida esperada

```text
--- Arturo ---
Arturo camina con armadura.
Arturo ataca con espada.

--- Robin ---
Robin corre.
Robin dispara una flecha con su arco.

--- Merlin ---
Merlin camina con su bastón.
Merlin lanza un hechizo.
```
